# Крестики-нолики (TicTacToe)

Классическая игра на поле 3×3. Первый, кто выстраивает три своих знака в ряд (по горизонтали, вертикали или диагонали), побеждает. При заполнении всего поля без победителя — ничья.

**Ключ в CLI:** `tictactoe`

---

## Схема состояния

```json
{
  "board": [
    [0, 1, 0],
    [0, 2, 0],
    [1, 0, 0]
  ],
  "current_player": 1
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `board` | int[3][3] | Поле: 0 = пусто, 1 = X (игрок 0), 2 = O (игрок 1) |
| `current_player` | int | Чья очередь (0 или 1) |

## Схема хода

```json
{"row": 1, "col": 2}
```

Индексы 0-based. Ход допустим только на пустую клетку (`board[row][col] == 0`).

---

## Боты

| Бот | Команда | Стратегия |
|-----|---------|-----------|
| Random | `python bots/random_bot.py` | Случайный ход из допустимых |
| Greedy | `python bots/tictactoe/greedy_bot.py` | Выигрыш → блок → центр → угол → случайный |
| Minimax | `python bots/tictactoe/minimax_bot.py` | Перебор всех позиций с alpha-beta отсечением, оптимальная игра |

### Greedy

Приоритеты по порядку:
1. Если есть выигрышный ход — сделать его
2. Если противник может выиграть следующим ходом — заблокировать
3. Взять центр (1,1)
4. Взять случайный угол
5. Любой допустимый ход

### Minimax

Полный перебор дерева игры с alpha-beta отсечением. На поле 3×3 максимум 9 ходов, дерево небольшое (~362к листьев), поэтому поиск мгновенный. Никогда не проигрывает при любом поведении противника.

## Результаты матчей

> Стартовая позиция: пустое поле 3×3, первым ходит игрок 0.
> Теоретически: два оптимальных игрока всегда заканчивают вничью.

### Random vs Random
**Победитель: Random (bot1) | Ходов: 9**

Все клетки заполнены, Random (bot1) выиграл — оба играют случайно, исход непредсказуем.

```
X O O
O X O
X X X    ← X выиграл по нижней строке
```

---

### Random vs Greedy
**Победитель: Greedy (bot2) | Ходов: 6**

Greedy взял центр на первом же ходу, заблокировал угрозу Random и выиграл по диагонали.

```
. X O
X O .
O . X    ← O выиграл по диагонали (0,2)→(1,1)→(2,0)
```

---

### Random vs Minimax
**Победитель: Minimax (bot2) | Ходов: 6**

Minimax занял центр, затем заблокировал единственную угрозу Random и выиграл по вертикали.

```
X O X
X O .
. O .    ← O выиграл по средней вертикали
```

---

### Greedy vs Minimax
**Результат: Ничья | Ходов: 9**

Ожидаемый исход: оба бота достаточно сильны, чтобы не проиграть. Greedy взял центр, Minimax контратаковал углом — ни один не смог выиграть.

```
O . X
X X O
O X X    ← ничья, поле заполнено
```

> **Вывод:** Minimax непобедим — он сведёт любую игру к победе или ничьей. Greedy достаточно силён чтобы против Minimax всегда добиться ничьей. Random против умных ботов проигрывает стабильно.

## Запуск матчей

```bash
# Greedy против Minimax
python run_match.py --game tictactoe \
  --bot1 "python bots/tictactoe/greedy_bot.py" \
  --bot2 "python bots/tictactoe/minimax_bot.py"

# Все случайные
python run_match.py --game tictactoe \
  --bot1 "python bots/random_bot.py" \
  --bot2 "python bots/random_bot.py"
```
