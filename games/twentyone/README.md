# 21 / Очко (TwentyOne)

Упрощённая версия карточной игры «21» (Blackjack/Очко). Оба игрока получают по 2 карты в начале и по очереди решают: взять ещё карту (hit) или остановиться (stand). Побеждает тот, кто наберёт больше очков, не превысив 21. При превышении — перебор (bust), автоматическое поражение.

**Ключ в CLI:** `21`

---

## Правила и особенности реализации

- Колода: стандартные 52 карты. Достоинства: 2–9 по номиналу, 10/J/Q/K = 10, Туз = 11 (автоматически считается как 1, если иначе перебор).
- Колода **перемешивается при каждом новом матче** — результат зависит от случая.
- Оба игрока видят **полное состояние** (включая карты противника) — это упрощение по сравнению с классическим блэкджеком.
- Ход чередуется: игрок 0 ходит, пока не встанет или не перебрал, затем игрок 1.
- При наборе ровно 21 игрок автоматически остановлен.
- Оба bust → ничья.

---

## Схема состояния

```json
{
  "hands": [[10, 7], [11, 5]],
  "deck":  [3, 8, 2, 10, ...],
  "done":  [false, false],
  "current_player": 0
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `hands` | int[2][] | Карты каждого игрока (значения: 2–11) |
| `deck` | int[] | Оставшиеся карты в колоде |
| `done` | bool[2] | Игрок встал или перебрал? |
| `current_player` | int | Чья очередь |

## Схема хода

```json
{"action": "hit"}    // взять карту
{"action": "stand"}  // остановиться
```

## Боты

| Бот | Команда | Стратегия |
|-----|---------|-----------|
| Random | `python bots/random_bot.py` | Случайно hit или stand |
| Cautious | `python bots/twentyone/cautious_bot.py` | Hit пока < 17, stand при ≥ 17 |
| Aggressive | `python bots/twentyone/aggressive_bot.py` | Всегда hit до 21 или bust |
| Probability | `python bots/twentyone/probability_bot.py` | Hit если P(bust) < 40% по остатку колоды |
| Counter | `python bots/twentyone/counter_bot.py` | Адаптируется к состоянию противника |

### Cautious

Стандартная стратегия казинного дилера. Хитует при значении < 17, останавливается при ≥ 17. Консервативна и предсказуема.

### Aggressive

Никогда не останавливается добровольно. Хитует до тех пор, пока не наберёт ≥ 21 (победа) или не перебрал. Высокий риск bust, но максимизирует шанс набрать 21.

### Probability

Вычисляет точную вероятность перебора по **реальным картам в колоде** (использует `state["deck"]`). Хитует только если `P(bust) < 0.40`. Единственный бот, явно использующий информацию о составе оставшейся колоды.

Вычисление:
```
P(bust) = |{карты в колоде, при добавлении которых hand_value > 21}|
          ─────────────────────────────────────────────────────────
                     |оставшихся карт в колоде|
```

### Counter

Использует полную информацию о состоянии противника:
1. Противник перебрал → **stand** (любая рука побеждает bust)
2. Противник встал и мы впереди → **stand** (зафиксировать победу)
3. Противник встал и мы позади или равны → **hit** (нужно догнать)
4. Противник ещё играет → **cautious fallback** (stand при ≥ 17)

## Результаты матчей

> В 21 результат одного матча сильно зависит от случайной колоды.
> Данные ниже — по одному матчу на каждую пару, не статистика.

### Random vs Cautious
**Победитель: Random (bot1) | Ходов: 2**

Random случайно встал на 6 очках, Cautious хитанул и набрал 24 (bust). Демонстрирует высокую дисперсию при малом числе матчей.

```
Игрок 0 (Random):  [3, 3] = 6   → stand (случайно)
Игрок 1 (Cautious): [9, 5] = 14 → hit → [9, 5, 10] = 24 BUST
```

---

### Cautious vs Aggressive
**Результат: Ничья | Ходов: 3**

Cautious перебрал первым (24 очка), Aggressive продолжил хитовать и тоже перебрал (30 очков). Оба bust → ничья.

```
Игрок 0 (Cautious):   [4, 10, 10] = 24  BUST
Игрок 1 (Aggressive): [9, 10, 11, 10] = 30  BUST
```

> Cautious перебрал с плохой раздачей. Aggressive — классическая потеря от жадности.

---

### Cautious vs Probability
**Результат: Ничья (20:20) | Ходов: 4**

Оба набрали по 20. Probability хитовал аккуратно, ориентируясь на состав колоды, и точно догнал Cautious.

```
Игрок 0 (Cautious):     [7, 3, 10] = 20  stood
Игрок 1 (Probability):  [7, 5, 8]  = 20  stood
```

---

### Cautious vs Counter
**Результат: Ничья (21:21) | Ходов: 3**

Оба набрали 21 — идеальный исход. Counter увидел что Cautious встал на 21 и продолжал хитовать пока не догнал.

```
Игрок 0 (Cautious): [2, 8, 5, 6] = 21  stood
Игрок 1 (Counter):  [5, 7, 9]    = 21  stood
```

---

### Aggressive vs Probability
**Победитель: Probability (bot2) | Ходов: 6**

Aggressive хитовал до bust (30 очков, 7 карт в руке). Probability встал на 17, которые и оказались достаточными.

```
Игрок 0 (Aggressive): [2,2,6,7,2,11,10] = 30  BUST
Игрок 1 (Probability): [10, 7]           = 17  stood
```

> Probability не стал рисковать при достаточной руке — рассчитал что P(bust) > 40% и встал.

---

### Probability vs Counter
**Победитель: Counter (bot2) | Ходов: 2**

Probability встал сразу на 19 (P(bust) была высокой). Counter увидел это, подсчитал что стоит стоять на своих 20, и выиграл без дополнительных карт.

```
Игрок 0 (Probability): [10, 9] = 19  stood
Игрок 1 (Counter):     [11, 9] = 20  stood → победа
```

> Counter использовал полную информацию: зная итоговую руку Probability, принял оптимальное решение.

## Статистика серий (--rounds)

Один матч в 21 нерепрезентативен из-за случайности колоды. Ниже — реальные результаты серий по 200 раундов.

### Probability vs Cautious — 200 раундов

```
Bot1 (probability_bot):  wins   80  (40.0%)
Bot2 (cautious_bot):     wins   96  (48.0%)
Draws:                         24  (12.0%)
Avg steps per round:           3.1
```

Cautious стабильно выигрывает чуть чаще. Probability хитует дольше (ищет правильный момент), но порог в 40% оказывается слишком агрессивным относительно стратегии дилера.

### Counter vs Cautious — 200 раундов

```
Bot1 (counter_bot):   wins   79  (39.5%)
Bot2 (cautious_bot):  wins   79  (39.5%)
Draws:                       42  (21.0%)
Avg steps per round:          3.0
```

Идеальная симметрия — Counter полностью адаптируется под противника, но так как Cautious предсказуем и сам по себе неплох, адаптация не даёт преимущества. Исход определяет только колода.

> **Вывод:** в 21 ни одна из детерминированных стратегий не даёт устойчивого статистического преимущества над другими при сравнимом уровне. Ключевой фактор — случайность раздачи.
