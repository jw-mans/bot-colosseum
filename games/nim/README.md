# Ним (Nim)

Классическая математическая игра. Есть несколько кучек камней (по умолчанию `[3, 5, 7]`). За ход игрок убирает любое положительное количество камней из одной кучки. Тот, кто забирает последний камень, **побеждает**.

**Ключ в CLI:** `nim`

---

## Теория: XOR-стратегия (Sprague-Grundy)

Ним полностью решён математически. Ключевое понятие — **nim-сумма**: XOR всех размеров кучек.

- `nim_sum == 0` → позиция **проигрышная** для текущего игрока (при идеальной игре противника)
- `nim_sum != 0` → позиция **выигрышная**: существует ход, делающий nim_sum равным нулю

Выигрышный ход: найти кучку `i` такую, что `piles[i] XOR nim_sum < piles[i]`, затем уменьшить её до `piles[i] XOR nim_sum`.

**Начальная позиция** `[3, 5, 7]`: `3 XOR 5 XOR 7 = 011 XOR 101 XOR 111 = 001 = 1 ≠ 0`.
Это **выигрышная позиция для первого игрока** — но в матчах Optimal всегда играет вторым (bot2), и nim_sum после первого случайного/жадного хода нарушается, давая Optimal выигрышную позицию.

---

## Схема состояния

```json
{
  "piles": [3, 5, 7],
  "current_player": 0
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `piles` | int[] | Размер каждой кучки |
| `current_player` | int | Чья очередь (0 или 1) |

## Схема хода

```json
{"pile": 1, "count": 3}
```

Убрать `count` камней из кучки с индексом `pile`. `count` должен быть от 1 до `piles[pile]`.

## Боты

| Бот | Команда | Стратегия |
|-----|---------|-----------|
| Random | `python bots/random_bot.py` | Случайный допустимый ход |
| Optimal | `python bots/nim/optimal_bot.py` | XOR-стратегия Шпрага-Гранди |
| Greedy | `python bots/nim/greedy_bot.py` | Забирает максимум из наибольшей кучки |
| Conservative | `python bots/nim/conservative_bot.py` | Всегда забирает 1 из наибольшей кучки |
| Copycat | `python bots/nim/copycat_bot.py` | Повторяет ход противника; при невозможности — 1 из наибольшей |
| Endgame | `python bots/nim/endgame_bot.py` | Случайный, пока камней > 6; затем XOR-оптимум |

### Особенность Copycat

Copycat хранит внутреннее состояние между ходами: запоминает кучки после своего хода, при следующем ходе вычитает разницу чтобы определить что сделал противник.

### Особенность Endgame

Порог переключения — `sum(piles) <= 6`. При стандартных `[3,5,7]` эндшпиль наступает поздно, но Optimal успевает поставить выигрышную позицию раньше.

## Результаты матчей

> Стартовая позиция: `[3, 5, 7]`, nim_sum = 1.
> Optimal всегда играет вторым (bot2) в матчах ниже.
> При nim_sum ≠ 0 у первого игрока есть теоретически выигрышный ход, но только Optimal умеет его находить.

### Random vs Optimal
**Победитель: Optimal (bot2) | Ходов: 6**

Random случайно нарушил позицию, Optimal восстановил нулевую nim-сумму и выиграл.

---

### Greedy vs Optimal
**Победитель: Optimal (bot2) | Ходов: 4**

Самый короткий матч среди всех. Greedy снёс всю большую кучку первым ходом, передав Optimal идеальную позицию для быстрой победы.

```
Ход 0 (Greedy):  [3,5,7] → [3,5,0]   nim_sum = 6
Ход 1 (Optimal): [3,5,0] → [2,5,0]   nim_sum = 7 → ищет ход дающий 0
...
```

> Greedy — худший из не-Optimal ботов против Optimal: агрессивное уничтожение кучек создаёт простые позиции, которые Optimal мгновенно эксплуатирует.

---

### Conservative vs Optimal
**Победитель: Optimal (bot2) | Ходов: 14**

Самый длинный матч (наравне с Copycat vs Optimal). Conservative максимально затягивает игру, но не меняет исход — Optimal терпеливо поддерживает нулевую nim-сумму.

---

### Copycat vs Optimal
**Победитель: Optimal (bot2) | Ходов: 14**

Copycat зеркалит ходы Optimal, что в Ним не работает как стратегия: зеркальный ход не сохраняет nim_sum. Матч затянулся так же как Conservative vs Optimal, но по другой причине — Copycat случайно играл неплохо в начале.

---

### Endgame vs Optimal
**Победитель: Optimal (bot2) | Ходов: 8**

Endgame играл случайно в начале, нарушив позицию, а при переключении на XOR-стратегию было уже поздно — Optimal уже держал контроль.

> **Вывод по Optimal:** Optimal выиграл **все** 5 матчей (4 различных противника + Random). XOR-стратегия в Ним — математически непробиваемый алгоритм из выигрышной позиции.

---

### Greedy vs Conservative
**Победитель: Greedy (bot1) | Ходов: 5**

Greedy быстро опустошил кучки; Conservative, забирая по 1 камню, не успел создать угрозу. Высокий темп Greedy оказался решающим против медленного Conservative.

---

### Copycat vs Endgame
**Победитель: Endgame (bot2) | Ходов: 8**

Endgame случайно играл в начале, затем переключился на XOR при малом числе камней и уверенно закрыл игру. Copycat не смог адаптироваться к смене стиля противника.
