# Вклад в проект

Вклад приветствуется! Добавляй новые игры, пиши ботов, исправляй баги — любые улучшения полезны.

---

## Что можно добавить

- **Новую игру** — реализацию любой пошаговой дискретной игры
- **Нового бота** — любую стратегию для существующей или новой игры
- **Исправление бага** — в движке (`colosseum/`), играх или ботах
- **Улучшение документации** — гайды, примеры, анализ матчей

---

## Как добавить игру

Подробная инструкция: [docs/creating-a-game.md](docs/creating-a-game.md)

Коротко:
1. Создать `games/{name}/game.py` с классом, наследующим `Game`
2. Реализовать 6 методов: `initial_state`, `valid_moves`, `apply_move`, `is_terminal`, `get_result`, `render`
3. Зарегистрировать в `GAME_REGISTRY` в `run_match.py`
4. Добавить `games/{name}/README.md` с описанием правил, схем и ботов

## Как добавить бота

Подробная инструкция: [docs/creating-a-bot.md](docs/creating-a-bot.md)

Коротко:
1. Создать файл в `bots/` (универсальный) или `bots/{game}/` (специфичный)
2. Бот читает JSON из stdin, пишет `{"move": ...}` в stdout
3. Язык программирования — любой

---

## Соглашения по коду

- **Состояние игры** — чистый JSON-сериализуемый `dict`, без мутаций
- **Ботам нельзя** зависеть от внутренней реализации игры — только на `state` и `valid_moves` из протокола
- **Без внешних зависимостей** — только стандартная библиотека Python (добавление зависимостей обсуждается отдельно)
- **Новая игра** должна работать с универсальным `random_bot.py` без изменений
